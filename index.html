🧠 GATARUJA - ORIENTAÇÃO A OBJETOS (CORE / CLI / API)

⚠ Ideia principal: CORE não sabe se é terminal ou web. CLI e API só usam o CORE.

---

📦 CORE.TS (Lógica de Negócio - OO)

✔ Aqui fica tudo importante do sistema

✔ Usa classe e this

❌ NÃO usa console.log, prompt, req, res

export class Sistema {
  termos: string[];

  constructor() {
    this.termos = [];
  }

  adicionar(termo: string) {
    this.termos.push(termo);
  }

  listar() {
    return this.termos;
  }
}
---

💻 CLI.TS (Terminal)

✔ Interação com usuário via terminal

✔ Usa console.log

✔ Só chama o core

import { Sistema } from "./core";

const sistema = new Sistema();

sistema.adicionar("HTML");
sistema.adicionar("CSS");

console.log(sistema.listar());
---

🌐 API.TS (Backend Web)

✔ Recebe requisições HTTP

✔ GET / POST

✔ Usa req e res

import express from "express";
import { Sistema } from "./core";

const app = express();
app.use(express.json());

const sistema = new Sistema();

app.get("/termos", (req, res) => {
  res.send(sistema.listar());
});

app.post("/termos", (req, res) => {
  sistema.adicionar(req.body.termo);
  res.send("ok");
});

app.listen(3000);
